
## Карта ачкычы (маанилүү)

`flutter run` жана Xcode'дун Run баскычы `--dart-define` бербейт, ошондуктан
`TWOGIS_API_KEY` бош болуп, бардык карталар 2GIS'тин
«Your MapGL key is invalid» экранын көрсөтөт.

Түзмөккө же симуляторго иштетүү үчүн ар дайым:

```bash
./run.sh                 # түзмөктү өзү сурайт
./run.sh <device-id>     # белгилүү түзмөккө
```

`run.sh` ачкычтарды `.env` файлынан алат. Ачкыч жок болсо скрипт токтойт.
Релиз билддери (`./build_ios.sh`, `./build_android.sh`) да ошондой текшерет.
